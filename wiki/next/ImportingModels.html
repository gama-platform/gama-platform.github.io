Importing models and projects

GAMA organizes models and their supporting files in projects in the current workspace. Use Project... to bring a complete project into the workspace, or Individual file... to copy selected files into a project that is already open.

Import a project​

Choose File > Import... > Project... to open the project importer.

In the Import GAMA projects wizard, choose a folder or an archive containing the projects. The wizard can search for projects inside nested folders. Select the projects to import, then choose whether to copy them into the workspace. When linking projects from their existing location, those files remain at that location; moving or removing them there can make the workspace project unavailable. Select Finish to import.

Import individual files​

Choose File > Import... > Individual file.... Choose Disk to select files from a folder or Archive to select files from a ZIP archive.

If no destination project was selected in the Navigator, GAMA asks you to choose an open project. The selected files are copied into that project.

If a project is distributed as a GAMA project archive, you can also open its .gamp or supported ZIP archive in GAMA and follow the import preview. Review the listed projects and choices before confirming the import.
