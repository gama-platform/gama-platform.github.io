Installing Plugins

Besides the plugins delivered by the developers of the GAMA platform, additional plugins add new functionalities to GAMA or enhance the existing ones. GAMA being based on Eclipse, plugins developed for Eclipse are also available, subject to the restrictions listed at the end of this page.

Installing GAMA extensions​

Open Support > Install GAMA extensions... to browse extensions published through the GAMA update sites. The menu groups available extensions by category. Its contents depend on the configured sites and the GAMA release; Refresh extension list requests an updated catalogue.

Choose Choose plugins to install... to open the plugin chooser, or select an extension directly from a category. The chooser shows available plugins and the selected items. Review the selection before completing the installation; Cancel closes the chooser without installing it.

The menu and chooser provide the current availability list. For usage instructions and requirements, consult the documentation maintained by the extension authors.

Installing GitHub Copilot​

Copilot is not part of the platform: it is maintained separately in gama.copilot, with its own dependencies, its own build and its own p2 site at https://gama-platform.org/gama.copilot/. It is offered directly by Support > Install GAMA extensions... > AI, LLMs, ML > Install GitHub Copilot for GAMA extension.... GAMA adds the upstream Copilot repository to the resolution on its own, so nothing has to be typed.

You need a GitHub account with access to a Copilot plan. GitHub offers a limited free plan for eligible individual users; available features and usage limits depend on the plan. Check GitHub's current Copilot plans. Copilot prompts you to sign in when authentication is needed. Its completion proposals appear in the GAML editor.

The models provided by a plugin​

Plugins that extend GAMA usually ship example models. They appear in the navigator under the category they are shipped in (models/<Category> inside the plugin, Library otherwise); there is no separate Plugin models node any more. If they do not show up, use Clean and update workspace... from the contextual menu of a category to relink the library to the current installation.

Installing an extension from another update site​

Open Support > Install third-party extensions... to use the standard Eclipse Available Software dialog. Enter an update-site address in Work with, or choose a saved site with Add... or Manage.... Select the features you want, then choose Next > to review the selection.

The community site uses the Eclipse release that GAMA is built on. For GAMA 2026-11, the address is https://updates.gama-platform.org/plugin/2026-06. The GAMA version number is not used in this URL.

Review the features and dependencies before completing an installation. Accept the licences required by the selected features, then follow the prompts to restart GAMA. The extension is available after the restart.

If the update site cannot provide a required dependency, or the extension requires a different Java environment, the wizard reports that the selection cannot be installed. Close the wizard and consult the extension's documentation for compatible versions.

Removing or updating a plugin​

Support > Manage extensions... opens the Gama Installation Details window. Its Installed Software tab lists everything the current installation contains, with the version and the identifier p2 knows it by, and gives four buttons at the bottom:

  • Uninstall... removes the selected feature. Select a row to enable the command. The confirmation page lists the feature and any dependent features before removal; GAMA then offers to restart.
  • Update... does the same in the other direction for a selected feature whose site publishes a newer version.
  • Properties shows, for the selection, the properties p2 recorded at install time.
  • Close leaves everything untouched.

The other tabs help when an installation went wrong: Installation History keeps a record of the states the installation has gone through, Features and Plug-ins list the same content at the two levels of granularity (a feature being the unit you install, the plug-ins being the bundles it contains), and Configuration shows how the platform is currently assembled.

Uninstalling does not clean the workspace: the models a plugin shipped stay visible in the navigator until the library is relinked, so finish with Clean and update workspace... from the contextual menu of the category, as described above. Support > Check for updates... concerns the platform itself and is described in Updating GAMA.

Restrictions​

GAMA resolves extension dependencies against the current installation. If the selected extension cannot be installed with the available dependencies, the installation wizard reports the conflict. GAMA does not change its Java execution environment to satisfy an extension; choose a compatible extension version instead. Plugin installation also requires a provisioned GAMA installation.

For automated or manual installation outside GAMA, follow the instructions supplied by the extension maintainer. Eclipse extensions can be packaged in different ways, so do not assume that copying a particular set of JAR files into dropins is sufficient. Restart GAMA after installing an extension.

If you have verified that an extension works with GAMA but it is not listed here, report it with its update-site address and compatibility information.
