Installation

GAMA is distributed as one application, in two flavours: a version that embeds the Java runtime it needs, and a lighter version that expects Java 25 to be installed on the machine, since the product refuses to start with an older runtime. The published archives without a suffix carry no runtime; the ones named ..._with_JDK... embed it. If you do not maintain a Java installation yourself, take the version with the runtime.

Download GAMA​

GAMA is published for Windows, macOS and Linux. The macOS releases are built twice, for Apple silicon and for Intel machines, and the downloads page offers both: the machine decides which one you need, not the version of macOS.

For advanced users:

  • Versions without an embedded Java runtime are published as well, as lighter archives. They require Java 25 on your computer.
  • It's also possible to download these 2 kinds of releases in simple zip archives (i.e. without installers), for Windows and Linux; the macOS releases come as .dmg only. If you do install from a zip archive on Windows, please refer to the post-installation procedure at the end of this page

You'll find them on the Github Release page

Install procedure​

After downloading the chosen GAMA version from the Downloads page for your computer, you only have to run the installer, follow the steps on the screen, and launch GAMA. Each platform also offers a command line route, described below.

Step-by-step Windows​

On Windows, in addition to running GAMA from the zip file, there are two ways of installing it: the standard installer that you can get from our website, or the winget command.

Installer from the website​

This is the standard way of installing GAMA on Windows.

  1. Download the installer .exe for Windows

  2. Double-click on the downloaded .exe file

  3. Choose the installation folder and any optional shortcuts in the setup wizard.

  4. Review the selected options, install GAMA, and finish the wizard. If Launch Gama is selected on the final page, the installer starts GAMA when you finish.

Windows may display a Microsoft Defender SmartScreen warning for an installer with limited reputation. If a warning appears, confirm that the installer came from the official GAMA downloads page and review the warning before deciding whether to continue; Windows security policy can prevent running it. SmartScreen behavior and wording vary by Windows version and device configuration.

NB: If you need to launch GAMA Headless, GAMA is installed under C:\Program Files\Gama by default

From winget​

For advanced users, you may want to install GAMA from winget, the process is very simple:

  1. Open PowerShell
  2. Run the command
winget.exe install GamaPlatform.Gama

That's it, GAMA is installed on your computer!

Step-by-step macOS​

On macOS there are two ways of installing GAMA: the .dmg installer, or the homebrew package manager from the command line.

DMG version​

  1. Download the installer .dmg for macOS

    • There is a build specifically for Apple silicon Macs (the M series). You can check which machine you have by clicking on the apple at the top left of the screen and choosing About This Mac: the window shows a Chip: line (Apple M...) on Apple silicon, and a Processor: line (Intel) on the older machines.

  2. Double-click on the downloaded .dmg file

  3. Drag the Gama icon onto the Applications shortcut of the window that opens

  4. Start GAMA from Applications. macOS may ask you to confirm the first launch or block the app if it cannot verify it. If you downloaded GAMA from the official downloads page and macOS blocks it, open System Settings > Privacy & Security, find the message for GAMA and choose Open Anyway, then confirm Open in the next alert. The wording and availability of this option depend on the macOS version and device policy; see Apple's instructions for safely opening apps.

NB: Note that the first launch of GAMA should be made in GUI mode (clicking on the icon) and not in headless mode. NB2: If you need to launch GAMA Headless after, GAMA is installed where you dragged and dropped the Gama.app

brew version​

  1. Install brew on your computer: just follow the instruction from the website.
  2. Open a terminal
  3. Run the command brew install gama-platform or brew install gama-jdk for the version with the embedded JDK

Step-by-step Linux​

Debian/Ubuntu based​

You have two ways of installing GAMA on Debian and Ubuntu based systems: either by downloading a .deb installer or from the ppa repository.

From the ppa to get the latest versions (Recommended)​
  1. Open a terminal.
  2. Run the following commands.
sudo -i # Type your password
apt update
apt install ca-certificates # This might be needed if you are on debian, install it just in case
echo "deb [trusted=yes] https://ppa.gama-platform.org ./" | tee -a /etc/apt/sources.list

  1. You can now install GAMA with the command apt install gama-platform or apt install gama-platform-jdk for the JDK version. If you want to see all available packages head over to the ppa page. The repository publishes amd64 packages only, and keeps two channels: gama-platform for releases, gama-platform-alpha for snapshots.

  2. If you want to update GAMA, just run apt update && apt upgrade when a new release comes out.

From a .deb installer to get a specific version​

  1. You can download a .deb file from 3 different sources:

    • From the project downloads page under the Linux section.
    • From the ppa page under the "All Packages" section.
    • From the github release page

  2. Double-click on the downloaded .deb file

  3. Click on install, which GNOME Software offers on the page of the package

  4. You could be asked for your password

  5. Done, you can start GAMA from your computer now

Note: If you need to launch GAMA Headless, GAMA is always installed under /opt/gama-platform

Arch Linux based​

AUR packages exist for both versions, with and without embedded JDK. You can download them with a command as follows:

yay -S gama-platform{-jdk}

Step-by-step Docker​

A Docker image of GAMA exists to execute GAMA Headless inside a container.

  1. Install docker on your system following the official documentation
  2. Pull the GAMA image you want to use (e.g. docker pull gamaplatform/gama:latest)
  3. Run the image with your headless command (e.g. docker run gamaplatform/gama:latest -help)

All the tags and more detailed documentation are on the Docker Hub and in the GitHub repository of the image.

System Requirements​

GAMA requires Java 25. Install a package with an embedded Java runtime if you do not already have a compatible Java installation. The memory limits used by GAMA depend on the package and platform. If GAMA fails to start or a model runs out of memory, see Memory problems before changing the launch configuration.

Windows post-installation setting (only for zip install)​

If you installed GAMA yourself from the zip archive, change the Windows high DPI compatibility settings first. To do so, go to your Gama.exe file, right click on it and select Properties, then go to the Compatibility tab and click on the Change high DPI settings button:

In the new window, check the Override high DPI scaling behavior option and select the System value.

These options are necessary to avoid most graphical problems when using GAMA on Windows.
