Inspectors and monitors

GAMA offers tools to obtain information about one or several agents. There are two kinds of such tools:

  • the agent browser (the Browser view), which looks at a whole population,
  • the agent inspector (the Inspector view), which looks at a single agent.

Monitors display the value of a GAML expression during a simulation.

Agent Browser​

The Browser view displays all agents of a species or a selected group. Open it from the Agents menu under the simulation and choose Browse <species> population.... The menu can also offer groups of individual agents. It lists species that currently have agents.

It displays in a table one line per agent, with a column per attribute: the tab itself is titled "Browse(0): population of prey". The attributes are listed on the left side of the view, under "Attributes": toggle each attribute to show or hide its column. Two commands complete the toolbar: Browse a species changes the population displayed in the table, and Save as CSV writes the agents and their attributes to a .csv file, so that the population can be examined later in another software.

Right-clicking on a line performs on that agent the same actions as right-clicking on it in a display: inspect it, focus on it, highlight it, kill it.

Agent Inspector​

The agent inspector provides information about one specific agent, and lets the modeler change the value of its variables while the simulation runs: each attribute is a field, colours are picked as they are in the rest of the interface. It is available from the Agents menu, from the contextual menu of a display (open the layer of the species, then the agent, then "Inspect"), from a line of the browser, or from the inspector of another agent.

The tab title and header identify the selected agent. Each attribute appears in its own row, with an editor suited to its value type: for example, a point has separate x and y fields, and a colour has a swatch. Rows can be reordered with their handles. The Actions row contains commands available for that agent.

Changing an attribute in the inspector takes effect immediately, but the model may assign it a different value during a later cycle. Pause the simulation before editing an agent that could be removed or whose values are updated by the model.

Highlighting draws a colored frame around the agent on every display; the color is the one given by "Default highlight color", in the "Default Rendering Properties" group of the Displays tab of the preferences (pref_display_highlight_color).

Monitor​

A monitor displays the current value of a GAML expression. A model can declare monitors with the monitor statement, as in the Predator Prey tutorial. With the default settings, the Parameters view includes a Monitors section for declared monitors, with controls to pause or remove each one.

A monitor can be defined inside a model (see this page) or through the interface.

During an experiment, choose Views > Add Monitor to define one through the interface. Enter the expression you want to follow in the monitor's editor.

To show the monitor list in a dedicated Monitors view, turn off Display monitors in the parameters view under Execution in Preferences. Expand a monitor in this view to edit its Title and Expression. When the expression evaluates successfully, the monitor header displays its current value.

For example, a monitor titled Total number of agents can use length(prey) + length(predator) to add the sizes of the two populations.

The expression is written in the GAML language. See this page for more details about it.
