2. BDI agents

This step adds miners that search for gold, extract it from mines and return it to the market. The agents use GAMA's simple_bdi control architecture to select plans from their beliefs, desires and intentions.

Beliefs, desires and intentions​

The BDI architecture maintains three agent-specific bases:

BaseMeaning in this model
BeliefsKnown mine locations, empty mines and other information about the world
DesiresGoals the miner could pursue, such as finding, extracting or selling gold
IntentionsThe goal the miner is currently pursuing

A predicate names information or a goal. A mental_state stores a predicate with its modality and other state, such as strength or lifetime. Perceptions add beliefs, rules infer desires, and plans act on the current intention. For the BDI architecture's research background, see Caillou et al. (2017) and Taillandier et al. (2016).

Define the predicates​

The model uses predicates to identify mine locations, empty mines and the goals that can be pursued.

global {
	int nb_mines <- 10;
	int nb_miners <- 5;
	market the_market;
	geometry shape <- square(20 #km);
	float step <- 10 #mn;
	string mine_at_location <- "mine_at_location";
	string empty_mine_location <- "empty_mine_location";

	predicate mine_location <- new_predicate(mine_at_location);
	predicate choose_gold_mine <- new_predicate("choose a gold mine");
	predicate has_gold <- new_predicate("extract gold");
	predicate find_gold <- new_predicate("find gold");
	predicate sell_gold <- new_predicate("sell gold");
}

Initialize a miner​

The simple_bdi control architecture provides the belief, desire and intention bases. Each miner begins with the desire to find gold.

species miner skills: [moving] control: simple_bdi {
	float view_dist <- 1000.0;
	float speed <- 2 #km/#h;
	rgb my_color <- rnd_color(255);
	point target;
	int gold_sold;

	init {
		do add_desire(find_gold);
	}

	aspect default {
		draw circle(200) color: my_color border: #black depth: gold_sold;
		draw circle(view_dist) color: my_color border: #black depth: gold_sold wireframe: true;
	}
}

Perceive mines and infer goals​

The perception records the location of each non-empty mine in a belief named by mine_at_location. It asks the miner itself to remove its current find_gold intention while keeping the desire, so the BDI architecture can select the next goal. The rules use beliefs to add stronger goals for extracting and selling gold.

perceive target: gold_mine where (each.quantity > 0) in: view_dist {
	focus id: mine_at_location var: location;
	ask myself {
		do remove_intention(find_gold, false);
	}
}
rule belief: mine_location new_desire: has_gold strength: 2.0;
rule belief: has_gold new_desire: sell_gold strength: 3.0;

Select and execute plans​

The first plan wanders while the miner is looking for gold.

plan lets_wander intention: find_gold {
	do wander();
}

When the miner intends to extract gold but has no target, it creates a sub-intention to choose a known mine and puts the current intention on hold. Once it has a target, it moves there and either extracts one nugget or records that the mine is empty.

plan get_gold intention: has_gold {
	if (target = nil) {
		do add_subintention(get_current_intention(), choose_gold_mine, true);
		do current_intention_on_hold();
	} else {
		do goto(target: target);
		if (target = location) {
			gold_mine current_mine <- gold_mine first_with (target = each.location);
			if (current_mine.quantity > 0) {
				do add_belief(has_gold);
				ask current_mine {
					quantity <- quantity - 1;
				}
			} else {
				do add_belief(new_predicate(empty_mine_location, ["location_value"::target]));
			}
			target <- nil;
		}
	}
}

The instantaneous choice plan removes known empty mines from the candidate list and selects the nearest remaining mine.

plan choose_closest_gold_mine intention: choose_gold_mine instantaneous: true {
	list<point> possible_mines <- get_beliefs_with_name(mine_at_location) collect (point((mental_state (each)).predicate.values["location_value"]));
	list<point> empty_mines <- get_beliefs_with_name(empty_mine_location) collect (point((mental_state (each)).predicate.values["location_value"]));
	possible_mines <- possible_mines - empty_mines;
	if (empty(possible_mines)) {
		do remove_intention(has_gold, true);
	} else {
		target <- (possible_mines with_min_of (each distance_to self)).location;
	}
	do remove_intention(choose_gold_mine, true);
}

When carrying gold, the miner returns to the market, removes the gold belief and increments its sales count.

plan return_to_base intention: sell_gold {
	do goto(target: the_market);
	if (the_market.location = location) {
		do remove_belief(has_gold);
		do remove_intention(sell_gold, true);
		gold_sold <- gold_sold + 1;
	}
}

Run the model​

The global initialization creates the market, mines and miners. The experiment displays them and charts the gold sold by each miner.

global {
	int nb_mines <- 10;
	int nb_miners <- 5;
	market the_market;
	geometry shape <- square(20 #km);
	float step <- 10 #mn;
	string mine_at_location <- "mine_at_location";
	string empty_mine_location <- "empty_mine_location";
	predicate mine_location <- new_predicate(mine_at_location);
	predicate choose_gold_mine <- new_predicate("choose a gold mine");
	predicate has_gold <- new_predicate("extract gold");
	predicate find_gold <- new_predicate("find gold");
	predicate sell_gold <- new_predicate("sell gold");

	init {
		create market {
			the_market <- self;
		}
		create gold_mine number: nb_mines;
		create miner number: nb_miners;
	}

	reflex end_simulation when: sum(gold_mine collect each.quantity) = 0 and empty(miner where each.has_belief(has_gold)) {
		experiment.pause();
		ask miner {
			write name + " : " + gold_sold;
		}
	}
}
experiment GoldBdi mode: gui {
	output {
		display map renderer: 3d {
			species market;
			species gold_mine;
			species miner;
		}

		display chart renderer: 2d {
			chart "Money" kind: series {
				datalist legend: miner accumulate each.name value: miner accumulate each.gold_sold color: miner accumulate each.my_color;
			}
		}
	}
}
